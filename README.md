# Flappy-Rocket
A flappy bird inspired game
A simple 2D space game made in Unity and C#.

The player controls a rocket and has to avoid asteroids and satellites while flying through space. The game is inspired by the gameplay of Flappy Bird.

## Features

- Rocket movement
- Asteroid and satellite obstacles
- Randomized obstacle positions
- Scrolling space background
- Collision detection
- Game Over screen
- Try Again button

## Built With

- Unity
- C#
- Visual Studio Code
